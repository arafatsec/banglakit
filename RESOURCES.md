# Bangla resources

A short list of projects and corpora that are useful next to banglakit. Each link was checked on 20 November 2026. Read the licence on the project before you copy its text. banglakit does not ship these corpora.

| Resource | What it is | Licence as published there | Link |
|---|---|---|---|
| Bangla Wikipedia dumps | Encyclopedia text | CC BY-SA 4.0 | https://dumps.wikimedia.org/bnwiki/ |
| Bangla Wikipedia | The live encyclopedia | CC BY-SA 4.0 | https://bn.wikipedia.org/ |
| bnlp | Python toolkit for Bangla NLP | MIT | https://github.com/sagorbrur/bnlp |
| BanglaBERT | Pretrained Bangla model from BUET | See the model card in the repository | https://github.com/csebuetnlp/banglabert |
| Indic NLP Catalog | Index of datasets for languages of the subcontinent, including Bangla | Catalog text; each dataset has its own licence | https://github.com/AI4Bharat/indicnlp_catalog |
| OpenBangla Keyboard | Bangla input methods | GPL-3.0 | https://github.com/OpenBangla/OpenBangla-Keyboard |
| Avro Keyboard | The phonetic layout banglakit follows | See the repository | https://github.com/omicronlab/Avro-Keyboard |
| ibus-avro | Avro for Linux | See the repository | https://github.com/sarim/ibus-avro |
| stopwords-bn | The stopword list shipped here | MIT | https://github.com/stopwords-iso/stopwords-bn |
| bn-ansi-to-unicode | The Bijoy mapping shipped here | MIT | https://github.com/BinduLogic/bn-ansi-to-unicode |
| bijoy-unicode | Another Bijoy converter, both directions | MIT | https://github.com/KovaPDF/bijoy-unicode |
| Unicode Bengali chart | The code chart for U+0980 | Unicode terms of use | https://www.unicode.org/charts/PDF/U0980.pdf |
| Bangladesh Bank MFS list | The provider table shipped in `data/mfs.json` | Bangladesh Bank public page | https://www.bb.org.bd/en/index.php/financialactivity/paysystems |

Do not train on these just because they are linked. Wikipedia is share-alike. Several model repositories restrict commercial use in the model card even when the code repository is permissive. OSCAR, Common Crawl and most news sites are not listed here because their Bangla text is not a clean open licence.
