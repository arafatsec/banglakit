# Install

Node 18 or newer. The package is not published from this repository. From a clone:

```bash
npm install
npm test
node bin/banglakit.js taka 125000.50
```

Once a release exists on npm:

```bash
npm install @arafatsec/banglakit
npx @arafatsec/banglakit --help
```

The evaluation sets in `datasets/` are not part of the installed package.
