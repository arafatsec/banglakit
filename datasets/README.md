# Training and evaluation sheet

Small gold sets generated by `node datasets/generate.mjs` from this repository. They are CC0. They are not part of the npm package. They are not a scraped corpus and they are too small to train a language model. Use them to score a tool or a model.

A prediction file is JSONL. Each line is `{"id","output"}`.

```bash
node datasets/generate.mjs
node datasets/eval.mjs datasets/numbers/train.jsonl
node datasets/eval.mjs datasets/numbers/train.jsonl predictions.jsonl
```

The first command rewrites the files. The second scores the library, which should be 100%. The third scores someone else's answers. Exact match is after Unicode NFC, trimmed, with the spaces collapsed.

| Dataset | Rows | What an answer must match |
|---|---|---|
| [taka](taka/README.md) | 8 | Cheque words, with paisa |
| [ordinals](ordinals/README.md) | 7 | প্রথম … and ২১তম |
| [dates](dates/README.md) | 373 | Every day of 2026, plus reform and leap days |
| [numbers](numbers/README.md) | 114 | Bangla words, including a Bangla-digit input |
| [hijri](hijri/README.md) | 4 | Tabular Hijri, not moon sighting |
| [phonetic](phonetic/README.md) | 23 | Avro-style input, no dictionary, including reph and backtick cases |
| [bijoy](bijoy/README.md) | 5 | Published Bijoy examples |
| [romanization](romanization/README.md) | 16 | Orthographic ISO 15919 |
| [normalization](normalization/README.md) | 3 | NFC and zero-width cleanup |
| [times](times/README.md) | 6 | Clock times with period names |
| [places](places/README.md) | 524 | BBS codes, and the district of upazilas whose English name is unique |

Counts are also in `manifest.json`, which the generator rewrites. Upazilas whose English name is shared (many are called Sadar) are left out of the place questions, because the question would have more than one answer.

Hugging Face layout, not uploaded: each folder has a dataset card (`README.md` with YAML), `train.jsonl` and `train.csv`.

## Original Bangla text

`text/` is not produced by `generate.mjs`. The sentences come from Tatoeba, Common Voice, and Bangla Wikipedia. Licences are split into folders. The CC BY-SA Wikipedia sentences are share-alike and stay in `text/cc-by-sa/`. Rebuild with `node datasets/curate-text.mjs` after the downloads in [text/README.md](text/README.md). `node datasets/eval.mjs` scores these files too.
